# 设备布局与鼠标切换设计规范

> 修订日期: 2026-06-12

## 概述

FlowGrid 需要一个可视化的设备布局编辑器，让用户定义各设备的虚拟空间位置关系。鼠标滑到屏幕边缘时自动切换到相邻设备，实现类似多显示器的无缝体验。

## 核心设计决策

| 决策 | 选择 |
|------|------|
| 空间模型 | 2D 网格（支持上下左右四方向切换） |
| 编辑方式 | 拖拽排列 |
| UI 位置 | 主窗口内嵌可折叠区域 |
| 切换行为 | 边缘穿透（鼠标到边缘自动切换） |
| 快捷键 | Ctrl+1/2/3 数字键 + Ctrl+方向键 |
| 切换过渡 | 屏幕渐变过渡（300ms） |
| 主机显示 | 当前主机也显示在网格中标记为"当前" |
| 分辨率 | 设备图标不显示分辨率 |

## 设备布局编辑器

### 位置

在主窗口的设备列表下方，作为可折叠区域（section）。

### 网格画布

- 背景：`#f8fafc`，虚线边框 `2px dashed #d9dee7`，圆角 `8px`
- 网格：3×3 格子，每格可放置一个设备图标
- 空位：显示虚线"+"占位符，提示"拖放设备"
- 拖拽：设备图标可拖拽到任意空位

### 设备图标

- 尺寸：56×56px，圆角 12px
- 颜色：使用平台主题色（macOS #007aff, Windows #0878d8, KDE #3daee9）
- 内容：2 字母缩写（如 MB、PC、LX）
- 标签：图标下方显示设备名（10px bold）
- 当前设备：绿色圆点标记 + "当前 · Ctrl+N" 提示

### 图例

画布底部显示图例说明：
- 绿色圆点 = 当前设备
- 箭头 = 鼠标边缘切换方向
- 键盘图标 = Ctrl+1/2/3 快捷键

## 切换机制

### 边缘穿透

鼠标滑到当前设备屏幕边缘时，自动切换到相邻设备：
- 左边缘 → 切换到网格中左侧设备
- 右边缘 → 切换到网格中右侧设备
- 上边缘 → 切换到网格中上方设备
- 下边缘 → 切换到网格中下方设备

### 过渡效果

切换时执行 300ms 渐变过渡：
1. 当前屏幕渐暗（opacity 1→0.3）
2. 新屏幕渐亮（opacity 0.3→1）
3. 新设备屏幕边缘蓝色光晕效果

### 快捷键

- `Ctrl+1/2/3`：切换到对应位置的设备
- `Ctrl+方向键`：切换到相邻设备
- 托盘菜单中显示快捷键提示

## 托盘指示器

### 当前设备区域

托盘顶部显示当前活跃设备：
- 设备图标 + 名称
- 切换快捷键提示

### 快速切换按钮

托盘中显示设备切换按钮行：
- 每个已连接设备一个小图标按钮
- 当前设备高亮显示
- 按钮下方显示对应快捷键编号

## 平台差异

| 元素 | macOS | Windows | KDE |
|------|-------|---------|-----|
| 区域圆角 | 10px | 7px | 7px |
| 图标圆角 | 12px | 10px | 8px |
| 主题色 | #007aff | #0878d8 | #3daee9 |
| 字体 | SF Pro Text | Segoe UI | Noto Sans |
| 按钮圆角 | 6px | 5px | 3px |

## 数据模型

```swift
// 设备布局位置
struct DevicePosition {
    let deviceId: String
    var gridX: Int  // 0-2 (3列)
    var gridY: Int  // 0-2 (3行)
}

// 布局配置
struct DeviceLayout {
    var positions: [DevicePosition]
    var gridSize: Int = 3  // 3x3 网格
}
```

## 交互流程

1. 用户打开主窗口 → 看到设备列表和"设备布局"折叠区域
2. 展开"设备布局" → 看到 3×3 网格画布
3. 拖拽设备图标到网格位置 → 布局自动保存
4. 鼠标滑到屏幕边缘 → 自动切换到相邻设备（渐变过渡）
5. 使用 Ctrl+1/2/3 → 快速切换到指定设备
