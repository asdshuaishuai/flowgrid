FlowGrid 设计系统 v2

托盘常驻 · 无主窗口。交互范式与窗口形态沿用上一版，本版只做视觉层重做与跨平台统一。

应用形态

应用没有常驻主窗口。唯一常驻的是托盘／菜单栏图标，所有界面都是按需唤出的浮板：唤出即来、失焦即走。浮板之间平级，不存在「窗口里套窗口」的层级。

托盘浮层（主入口） 设备与连接 设置 添加设备 网络延迟 键位映射 剪贴板 文件传输

完整保留：上一版的窗口几何

精致度打磨没有触碰任何窗口几何与动效参数：浮板仍是 520px、阴影第一层仍是 0 18px 42px rgba(24,30,44,.14)、入场仍是 220ms。新增的顶部内高光是叠加层，不是替换。

第二轮：精致度打磨

维度做法
浮板质感在原阴影之后叠加 inset 0 1px 0 顶部内高光——原生窗口都有的那道亮边，浮板因此真正「浮」起来。原阴影值未被替换
边框克制line-1 .08→.07、line-2 .14→.12，新增 hairline .055。线越淡越精致，1px 仍清晰可辨
文字层次主文更深、次级更柔，层级靠明度差而非只靠字号；新增 hairline 级分隔线区分「结构线」与「装饰线」
字距新增 5 档字距令牌。20px 以上收紧 -0.022em、13~15px -0.012em、11px 放开 +0.012em、全大写小标题 0.04em
按钮反馈filter: brightness() 换成明确的明度令牌，深浅主题各自取方向（浅色 hover 压暗、深色 hover 提亮），不再越点越闷
衬底纯色底改为顶部极淡光晕渐变，呼应上一版 linear-gradient(#fbfcfd → #eff2f6) 的通透感
深色主题衬底压深至 #101215，浮板与桌面拉开距离；Toast 改用中性石墨而非蓝调深灰

四平台统一策略

结构、间距、字号、圆角、动效、交互、文案四平台逐像素一致。只有两类值保留平台映射，其余一律继承全局语义令牌。

平台主色映射字体族窗口控件
macOS--c-accent-rgb: 0 122 255SF Pro Text / PingFang SC红黄绿三点，靠左
Windows--c-accent-rgb: 8 120 216Segoe UI Variable / 微软雅黑扁平三键，靠右
KDE Plasma--c-accent-rgb: 61 174 233Noto Sans / Noto Sans SC扁平三键，靠右，深色标题栏
deepin--c-accent-rgb: 0 129 255Source Han Sans SC扁平三键，靠右
主色跟随平台原生色，是「平台视觉规范」的一部分，也是上一版就有的特征。强行统一会让 deepin 违反 AGENTS.md 的 DTK 语义色硬约束、让 KDE 脱离 Breeze、让 macOS 端看起来像 Windows 应用。用右上角开关可在四个平台间实时对照。
