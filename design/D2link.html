FlowGrid 开发文档

基于自研 NearLink 协议，无需路由器，BLE 发现 + Wi-Fi Direct 直连，实现 <3ms 端到端键鼠共享，并内置自适应 Win ↔ Mac ↔ Linux 修饰键重映射。

01 产品定位与核心痛点

Deskflow 的根本问题

  • 传输层缺陷：强依赖 TCP，Nagle 算法会积累小数据包。HID 事件恰好是 8 字节的极小帧，完全触发该算法的最差情形，引发 40–120ms 累积延迟。
  • 连接发现困难：手动输入 IP + 端口；企业/大学网络 mDNS 被禁时无法自动发现。
  • 键位无感知适配：Ctrl/Cmd/Win/Alt 跨系统切换全靠手动配置，没有 OS 感知能力。
  • 协议碎片化：与 Barrier / Input Leap 协议撕裂，社区无法收拢。

02 系统分层架构

L1

用户界面层 (UI Shell)

系统托盘常驻 · 一键配对向导 · 实时延迟显示 · 键位可视化编辑器 · 多显示器布局拖拽

L2

OS 感知重映射引擎 (KeyMapper)

检测连接双端 OS 类型 → 加载对应规则表 → 拦截 HID 扫描码 → 转换后注入目标 OS 输入栈；支持应用上下文切换规则 (YAML 热重载)

L3

NearLink / DirectLink 传输层 (Transport)

BLE 5.0 广播发现 → Wi-Fi Direct P2P 建连 (<800ms) → DTLS 1.3 加密信道 → UDP HID 帧发送器 (8字节/帧，批量压缩 + 鼠标插值平滑) → 自动断线重连 (<200ms)

L4

平台 HID 抽象层 (Platform HAL)

Windows: SendInput / Raw Input API · macOS: IOKit HID + CGEventTap · Linux: libei / uinput / libportal · 统一 HID 事件格式，跨平台消除差异

L5

物理硬件 / 网络层

Wi-Fi 802.11n/ac/ax (社交信道 6/44/149 避开 AWDL 抖动) · 蓝牙 5.0 BLE · 以太网 (降级回退路径)

03 NearLink 无线协议设计

设计逻辑：来自 AirDrop 的启发。用 BLE 低功耗广播来发现设备，发现后建立 Wi-Fi Direct 点对点连接，整个过程完全不依赖路由器。关键是将 TCP 换成 UDP+DTLS：实验表明，UDP 在局域网能以 3.25ms 内达到 99.9% 的包投递率。主动避开 Apple 占用的社交信道 (6/44/149) 以规避 AWDL 3–90ms 的周期性抖动。

04 DirectLink 有线协议设计

场景定位：现有所有软件 KVM 均假设设备接入同一路由器子网。无 Wi-Fi 台式机、隔离机房工作站、嵌入式开发板是完全被遗忘的场景。DirectLink 专为此而设计，一根网线即完整。物理隔离，零无线干扰，千兆以太网 RTT <0.3ms。

零配置自协商时序 (插线后)

RFC 3927 链路本地寻址

检测到新以太网接口 → 进入 APIPA 模式。随机选取 169.254.x.x/16 地址，ARP 冲突探测 (发 3 个 ARP probe)，无冲突后启用。全程自动，用户无感，约 2–4 秒完成。不影响机器其他网卡/路由表，完全隔离。

专属 /30 子网协商

握手后双方协商一个专用 /30 子网 (仅 2 个可用 IP，如 192.168.254.0/30)。该子网仅在 FlowGrid 虚拟网卡上生效，不写入系统路由，防止与业务网段冲突。设备配对成功后记忆子网，下次插线即通，0 秒重连。

有线帧格式 (Raw Ethernet Frame)

直接走原始以太网帧 (EtherType 0xF1A0)，绕过 IP/UDP 栈，进一步压低延迟。合计 17B / 帧，无需 IP 头开销。

安全模型 · 有线场景

  • 首次连接：ECDH P-256 密钥交换，生成会话密钥。
  • 设备指纹：MAC 地址 + 硬件序列号哈希，绑定信任关系。
  • 帧认证：每帧附 4B HMAC 截断值，防局域网内嗅探注入。
  • 物理安全前提：有线直连本身已是强信道隔离。可选完整 DTLS (高安全场景启用，延迟约增加 0.1ms)。

系统适配细节

Windows 端
  • 检测到新以太网适配器 → 自动设置 APIPA。
  • 若 APIPA 被组策略禁用，通过 WinAPI AddIPAddress 以服务权限添加链路本地 IP。
  • 网卡绑定：通过 GUID 精确绑定 DirectLink 到指定适配器。
  • 防火墙规则：安装时自动添加入站规则，开放 UDP 24801。
  • 驱动层：使用 WinPcap/Npcap raw socket 实现以太网直连帧模式。
Linux 端
  • systemd-networkd / NetworkManager 均支持链路本地 IP 自动分配。
  • avahi-daemon 提供 mDNS 广播 (多数桌面发行版已预装)。
  • raw socket 模式：使用 AF_PACKET / SOCK_RAW，需要 CAP_NET_RAW 能力。
  • 安装时通过 setcap cap_net_raw+eip 授予二进制能力，无需 root 运行。
  • udev 规则：检测以太网 link up 事件，自动触发 DirectLink 握手。
