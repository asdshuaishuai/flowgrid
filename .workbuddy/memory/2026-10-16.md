# 2026-10-16

## 统一设计系统（design/unified/）

**背景**：旧设计稿在 Windows / macOS / KDE / deepin 四端各写一套（`design/win|mac|kde/` + 根目录散落的 `flowgrid-*-main.html`），主色 4 套、圆角 5 种、开关两种尺寸、导航结构三种、设置分组三套、深色主题只有 KDE 有半个。用户在四端切换需重新学习。

**方案**：新增 `design/unified/`，采用**三层令牌架构**，不覆盖旧稿（旧稿保留作参考）。

- **Layer 1 Primitive** — 纯色阶与数值，无语义
- **Layer 2 Semantic** — 全平台唯一语义名（`--fg-accent` / `--fg-surface` / `--fg-text-1` …），light/dark 双值，组件只允许消费这层
- **Layer 3 Platform** — macOS / Windows / KDE / deepin 各自映射到实际色值、字体、圆角

**为什么分三层**：做三套换皮会把割裂从视觉层搬到维护层；强行统一配色会违反 `AGENTS.md` 里「deepin 必须用 DTK 语义色、KDE 必须跟 Breeze」的硬约束。三层是唯一能同时满足"统一"和"原生"的做法——新增平台只需加一段映射。

**刻意保留的平台差异**（刻意不抹平）：主色、圆角尺度、字体族、窗口控件位置、菜单栏 vs 托盘锚点、快捷键符号（⌘ vs Ctrl）。

**被消灭的差异**：导航模型统一为「单窗口 + 左侧导航」（三端唯一都原生成立的模式，替代 macOS/Windows 的窗口内折叠区 + 子弹窗）；设置统一为左侧分类 + 右侧分组列表；开关统一 38×21（macOS 40×23）；托盘菜单结构与文案统一；深色主题全量支持。

**文件**：
- `tokens.css` — 三层令牌 + 四平台皮肤
- `ui.css` — 全部组件（组件层禁硬编码色值/字体）
- `app.js` — 交互层：外壳注入、主题/平台切换、hash 路由、Toast、状态机、向导、实时延迟模拟
- `index.html` — 设计系统总览（原则、四平台对照、统一了什么、令牌、组件陈列、交互规范、实现约束）
- `screens/` — devices / clipboard / latency / keymap / settings / pairing / tray 七屏

**平台配置路径差异**（settings.html 内 `CFG` 映射）：macOS `~/Library/Application Support/FlowGrid/settings.yaml`、Windows `%APPDATA%\FlowGrid\config.json`、Linux 系 `~/.config/flowgrid/settings.yaml`。

**踩过的坑**：
1. `el?.closest(x).hidden = true` — 可选链后直接赋值是 `Invalid left-hand side` 语法错误，必须拆开判空
2. 设置页 `paint()` 用 `body.parentElement.innerHTML` 替换会吞掉 `[data-route-head]` 页头 → 改用 `replaceWith` + 显式补页头
3. 设置页有 `[data-route-body]` 会被 app.js 的 hash 路由接管，`hashchange` 时用 devices 路由覆盖本页 → 加 `<body data-no-route>` 让 app.js 在 `initHashRoute` 早退
4. 静态校验脚本要剔除 `<script>` 内容再查标签配对，否则 JS 里的 `<` 会造成误报

**校验方式**：agent-browser 未安装（需下载 500MB Chromium），改用 Node 静态校验——JS 语法（`node --check` + `new Function` 验内联脚本）、CSS class 引用完整性（含模板三元动态拼接的 class）、图标名有效性、HTML 标签配对。四类全绿。

**未做**：浏览器实机截图验证。装好 agent-browser 后建议补一轮，重点看浅色/深色 × 四平台 × 七屏的排版与对比度。

## v2 重做：回退窗口形态，只做视觉层（同日）

**用户反馈**：上一版（v1）改错了方向——把导航模型改成「单窗口 + 左侧导航」，但 FlowGrid 是**托盘常驻、无主窗口**的应用（`AGENTS.md` / `CLAUDE.md` 均写明 "System tray resident app"）。v1 属于交互范式替换，必须回退。

**项目形态硬约束（务必记住）**：
- 无主窗口，唯一常驻入口是托盘／菜单栏图标（mac = 菜单栏，win/kde/deepin = 托盘/SNI）
- 所有界面都是**按需唤出的浮板**，唤出即来、失焦即走，浮板之间平级
- 不存在「窗口里套窗口」的层级

**v2 原则**：沿用上一版交互与窗口形态，只重做视觉。

**保留的窗口几何（逐像素搬自 09:57 那批原稿，不可改）**：
| 项目 | 值 | 来源 |
|---|---|---|
| 浮板宽 | `520px` | 三平台原本就一致 |
| 浮板 max-height | `calc(100vh - 48px)` | 三平台一致 |
| 浮板阴影 | `0 18px 42px rgba(24,30,44,.14)` | 三平台一致 |
| 托盘阴影 | `0 16px 32px rgba(15,23,42,.16)` | win/kde 原值 |
| 标题栏高 | `34px` | mac/win 原值（kde 30px） |
| 内容边距 | `14px` | 三平台一致 |
| 控件高 | `28px` / 图标按钮 `26px` | 三平台一致 |
| 开关 | `36×20`，滑块 `16` | mac 原值（win/kde 34×18） |

**唯一被收敛的窗口参数**：圆角。上一版 6(KDE)/8(Win)/12(mac)，统一取 `12px`（跨平台统一要求 vs 圆角一致要求冲突时的取舍）。

**保留的动效节奏**：入场 `220ms` `cubic-bezier(.16,1,.3,1)` + `translateY(-8px)` + `scale(.96~.97)`；折叠 chevron `rotate(-90deg) 200ms`；拖拽 `grab/grabbing` + hover `scale(1.05)`；切换设备全屏遮罩 `rgba(0,0,0,.15)` + 居中提示 `scale(.8→1) 300ms`；Toast 底部居中 `translateY(80px)→0 300ms` 停留 `1800ms`；状态点 `pulse 2s`；延迟采样 `2000ms` 区间 `1.5~3.0ms`；微交互 `150ms cubic-bezier(.4,0,.2,1)`。

**视觉精进**：emoji/字符（🔊📶⌚、`_ □ × ▼`）→ 统一 SVG 图标集（24 网格 / 1.75 描边 / 圆头圆角）；圆角 10 种 → 3 级（6/10/12 + pill）；字重 `650/800` → 4 档（400/500/600/700）；取消 10px 以下字号，阶梯 `11/12/13/15/20/28`；间距收敛为 4 的倍数；配色散值 → 三层令牌，语义色各 4 层级；全量 light/dark 双主题；新增 `:focus-visible` 焦点环与 `prefers-reduced-motion` 降级。

**文件**：`design/unified/` 下 `tokens.css`（第 0 节即窗口几何常量）/ `ui.css` / `app.js` / `index.html` / `screens/{tray,connections,settings,pairing,latency,keymap}.html`。已删除形态不合的 `devices.html`、`clipboard.html`（内容并入 connections 折叠区）。旧稿 `design/win|mac|kde/` 未动。

**本轮新增踩坑**：
1. 平台切换时用 `outerHTML` 替换 `[data-dock]`/`[data-titlebar]`，会把标记属性一起吃掉 → 第二次切换失效。改为外层元素由页面持有（`<div class="dock" data-dock>`），只 `innerHTML` 换内部结构。
2. `startLatency()` 在平台切换时被重复调用会叠加定时器 → 加 `latencyTimer` 守卫，且每 tick 重新 `querySelectorAll`，这样新渲染的节点也能被覆盖。
3. 图标集漏定义 `search`（macOS 菜单栏会渲染空图标）、CSS 漏定义 `.t-28` / `.row-2` —— 静态校验能抓出来。

## v2.1：链路改名 + 精致度打磨（同日）

**链路命名（用户明确要求，有商标风险顾虑）**：
- 近距离高速链路：`NearLink` /「星闪」→ **`LittleLink`**（自有命名）。旧稿中共 120 处 `NearLink` + 9 处中文别称，属历史归档未改；复用旧稿文案时需一并替换。
- 局域网直连：**沿用英文原名 `DirectLink`**，与 `PROTOCOL.md` 一致（64 处）。
- 已替换位置：`unified/` 下 connections（设备元信息、页脚）、latency（当前链路、分设备）、settings（优先链路下拉的三个 option 与 hint）、index（排版样例文案）。
- 注意：不要在设计稿或产品文案中再出现第三方链路品牌名。

**精致度打磨（未触碰任何窗口几何与动效参数）**：
- 浮板质感：在原阴影**之后叠加** `inset 0 1px 0 var(--fg-edge-hi)` 顶部内高光（原生窗口都有的那道亮边）。`--shadow-panel` 原值 `0 18px 42px rgba(24,30,44,.14)` 一字未改，叠加不是替换。
- 边框更克制：`line-1` `.08→.07`、`line-2` `.14→.12`，新增 `hairline .055` 区分「结构线」与「装饰线」（列表行、折叠区、分隔线、页脚用 hairline）。线越淡越精致，1px 仍可辨。
- 文字层次：主文更深 (`#171b21`)、次级更柔 (`#5f6875`/`#8b93a0`)，层级靠明度差而非只靠字号。
- 新增 5 档**字距**令牌：`--ls-tight -.022em`（20px+）、`--ls-snug -.012em`（13~15px）、`--ls-normal 0`、`--ls-wide +.012em`（11px）、`--ls-caps .04em`（全大写小标题）。这是排版精致度的关键杠杆。
- 按钮反馈：`filter: brightness()` → 明确的明度令牌 `--fg-accent-hover/--fg-accent-press`，深浅主题**各自取方向**（浅色 hover 压暗 91%/press 84%；深色 hover 提亮 88%/press 76%），避免深色主题下越点越闷。
- 衬底：纯色底 → 顶部极淡光晕渐变（`radial-gradient(140% 90% at 50% -12%)`），呼应上一版 `linear-gradient(#fbfcfd→#eff2f6)` 的通透感。
- 深色主题：衬底压深至 `#101215`，浮板与桌面拉开距离；Toast 改中性石墨 `rgba(46,51,60,.96)` 而非蓝调深灰。
- 中性灰阶从纯中性改为略带冷调的石墨（更耐看）；新增 `--shadow-lift` 令牌替换 `.device:hover` 里一处硬编码 rgba。

**校验**：命名无残留（仅总览页说明文字保留可检索的 `NearLink`）；令牌 121 定义 / 21 引用全部有效；class 全部有定义；7 个文件标签配对与内联脚本语法通过；窗口几何常量逐项复核未变。

**仍未做**：浏览器实机截图。agent-browser 未安装（需 500MB Chromium）。

## v2.3：新增剪贴板与文件传输两屏（同日）

**背景**：协议层 `protocol/clipboard.go` 与 `protocol/filetransfer.go` 已实现，openspec 规格在 `openspec/changes/archive/2026-10-16-protocol-v1-1/specs/{clipboard-segmentation,file-transfer}/`。UI 此前只有一个 connections 折叠区，需提升为独立浮板。

**新增文件**：`screens/clipboard.html`（当前内容预览 + 类型过滤 + 关键字搜索 + 历史 50 条 + 同步设置）、`screens/files.html`（进行中进度 + 拖放发送 + 传输记录 + 接收设置）。两者都是托盘唤出的 520px 浮板，窗口几何/动效与其他六屏完全一致，未引入新交互范式。

**界面上的边界值全部取自协议实现，不要改成示意数字**：
- 剪贴板：单条上限 `63,240 B`（分段上限，`255 × (248 - M)` 空 MIME）、重组超时 `5s` 整份丢弃、同刻仅一路传输。
- 文件：单文件 `1 B ~ 16 MiB`、分块 `249 B`（`MaxFileChunk`）、提议未确认 `30s` 失效（`FileOfferTimeout`）、无进展 `10s` 判失败（`FileIdleTimeout`）、SHA-256 校验通过后才写入目标路径、同一方向同时仅一路。
- ACK 状态 6 种映射为徽标：完成 / 已拒绝(busy) / 用户拒绝 / 超限 / 校验失败(哈希不符) / 超时。

**组件库扩展**：`app.js` 图标集新增 `file` `upload` `download` `folder`（24 网格 1.75 描边，与既有风格一致）；`ui.css` 新增 `.preview`（当前剪贴板预览）、`.bar`/`.bar__fill`（进度条）、`.xfer` 系列（传输行）、`.drop`（拖放区）。删掉了定义但没用上的 `.clip--stack` / `.clip__body` / `.clip__src` / `.clip__size` / `.dir--in` / `.bar__fill--warn|danger`。

**踩坑**：语义色软底令牌命名是 `--fg-ok-soft` / `--fg-warn-soft` / `--fg-danger-soft`，不是 `--c-*-soft`（`--c-*`-soft 不存在）。写 `--c-ok-soft` 会静默失效、图标没有底色。另外校验脚本此前只查 HTML/app.js 的 `var()`，**漏了 ui.css 自身的令牌引用**，本轮补上后才抓到这三个。

**入口已接通**：托盘菜单新增「数据与同步」组（剪贴板 / 文件传输）；8 个屏幕的 pager 互链；connections 的剪贴板折叠区加「详情」，并新增文件传输折叠区摘要；index.html 入口区与文件构成（八个界面）+ 新增「剪贴板与文件传输」约束对照表。
